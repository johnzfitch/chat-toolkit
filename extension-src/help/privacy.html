CHAT TOOLKIT · VERSION 1.7.0

Your conversations, in a file you control.

Copy or save the conversation you have open as Markdown (.md), JSON (.json), or HTML (.html): all messages, only yours, or only the assistant's.

Use the Chat Toolkit panel on a supported chat page, or the extension's toolbar button. Sign in to the provider in that tab and open a saved conversation first. Supported sites are Claude, ChatGPT, Grok at grok.com, Gemini, Google AI Studio, and OpenRouter.

The available history depends on what the provider returns. Exports retain supplied reasoning, citations, tool results, and attachments where supported. Chat Toolkit cannot recover reasoning or messages the service does not expose. Some sites or conversation types use the visible page as a fallback; content that was not loaded may be absent.

Privacy policy

Effective September 24, 2026, for Chat Toolkit 1.7.0.

Created by Zack Fitch. Licensed under the MIT License, copyright 2026 Zack Fitch. For support or privacy questions, email zack@definitelynot.ai.

Chat Toolkit has no developer-operated collection server, analytics, advertising, or automatic report uploads. It processes conversations in your browser. Save file writes to your downloads folder; Copy writes to your clipboard.

When you request an export or an API diagnostic, Chat Toolkit contacts the current chat provider over HTTPS using your existing signed-in session. Requests can include the provider's session cookies or access token, conversation and message identifiers, organization or project identifiers, and request metadata needed to retrieve the selected content. These requests go to the provider, not to the extension's developer. The provider's own privacy policy applies to its services.

Firefox's installation prompt declares authentication information and website content for those authenticated requests and their cookies, identifiers, and request metadata. Chat Toolkit does not ask you to enter a password or buy a separate extension account.

Optional diagnostics

Diagnostic reports can contain private conversations, account information, URLs, request bodies, and tool results. Inspect a report before sharing it. Reports appear in the chat page's panel and may also appear in that tab's developer console.

  • API inspector, Page inspector, and Compare API and page inspect the current conversation's provider data, the visible page, or the differences between them.
  • Network inspector records this tab's request metadata from when you select it until you select it again. Diagnostic capture saves conversation data, page details, and bounded network diagnostics recorded while the capture runs.
  • Record research starts local recording of ChatGPT research responses and related events in this tab. Stop recording stops new recording. Clear recording removes recorded data. A small red light in the panel's title bar shows while any recording, the Network inspector, or page hooks are active. Recording starts off; navigating, reloading, or closing the tab clears the background recording. Memory can also be discarded when Firefox unloads the extension background page. No recording is restored in a different tab or container.
  • Fetch ChatGPT research state sends an authenticated request to ChatGPT for research sessions found in this tab's recording. It runs only when you click it.
  • Account capture additionally requests available account and session information. On Claude this can include organization details, settings, memory, project files, tool configuration, and code-session metadata. On ChatGPT it requests a limited set of conversation and custom GPT metadata. This is separate from ordinary exports and Diagnostic capture.
  • Enable page hooks allows request instrumentation in this page during an explicit capture. This may affect site behavior. Reload the page to remove the hooks. The website cannot enable them through its local storage.

Background recordings use bounded in-memory buffers. They are not written to extension storage. Clear also removes legacy diagnostic caches left by earlier local versions. In private windows the Network inspector, Diagnostic and Account capture, research recording, and page hooks are refused. Files and clipboard contents that you explicitly export remain until you delete or replace them; Clear does not remove those copies.

Why Firefox requests permissions

  • Access to supported sites: read the current conversation and request its history using your signed-in session.
  • Downloads and clipboard: save exported files and copy formatted conversations.
  • Storage: remember the panel's position, your message and file-type choices, and sites where you hid the panel. No conversation content is stored, and nothing is written from private windows.
  • Web requests: implement the optional Network inspector and Diagnostic capture tools; they are only connected while one of these runs. Response bytes are forwarded unchanged to the site.

If an export fails

Open a saved conversation, confirm you are signed in, and reload the page after installing or updating the extension. If the provider has changed its API, use DOM diagnostics to inspect what is visible. Keep private exports and HAR files out of public issue reports.
